About the science

Paper inspiration: Bi-FORK by Anna Zimmel, Fleur Hendriks, Markus Holzleitner, Florian Sestak, Martin Weichselbaumer, Vlado Menkovski and Johannes Brandstetter (CC BY 4.0). The split-beam idea comes from the paper; we added a hands-on branch picker and a nine-seed visual comparison. Locally generated toy trajectories use a declared sine-mode rule. They are not Bi-FORK output, validated mechanics, or evidence about real branch likelihoods. This demo does not use the paper's code, data, weights, or assets.
